# Security Policy

## Supported Versions

Only the latest release of CivilEG 2 is actively supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately to **engahmed121314@gmail.com**.

Please do **NOT** open a public issue for security vulnerabilities.

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (if available)

### Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial Assessment**: Within 5 business days
- **Resolution**: As soon as a fix is available

## Security Measures in CivilEG 2

- Play Integrity API integration for tamper detection
- AES encryption for sensitive local data
- No sensitive data transmitted over unencrypted channels
- Hilt-managed dependency injection to prevent service injection
